# Autoclicker

Настраиваемый автокликер с интерфейсом tkinter/ttk. Python 3.10+.
Компактное окно повторяет предоставленный автором макет: стандартные Windows-
элементы, группы Click interval / Click options / Click repeat / Cursor position
и четыре кнопки внизу. Шрифты и отступы учитывают масштаб Tk/Windows.
Веб-сервиса, аккаунтов и телеметрии нет.

## Установка и запуск

Скачайте репозиторий (Code → Download ZIP) и распакуйте его либо клонируйте:

```console
git clone https://github.com/IliyasNU/autoclicker-in-python.git
cd autoclicker-in-python
python -m venv .venv
```

Windows:

```console
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python autoclick.py
```

Linux/macOS (экспериментально, вручную не проверены):

```console
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python autoclick.py
```

`tkinter` входит в официальный установщик Python для Windows. В Linux может
понадобиться пакет Tk из дистрибутива. Единственная прямая внешняя зависимость —
`pynput`, уже использовавшийся в исходной версии; он управляет мышью и слушает
глобальные клавиши. На macOS могут требоваться разрешения ОС на управление
вводом. На Linux работа зависит от графической сессии; Wayland не проверен.

## Управление

1. В Click interval задайте `hours`, `mins`, `secs`, `milliseconds`.
   Интервал — сумма этих четырёх полей; неиспользуемые поля заполните нулями.
   Часы — целые неотрицательные, минуты и секунды — целые от 0 до 59,
   миллисекунды — от 0 до менее 1000 (дробная часть через точку).
   Минимальный суммарный интервал — 1 мс. Например: 0 / 0 / 1 / 250 = 1.25 с.
2. В Click options выберите `Left` (левая), `Right` (правая), `Middle` (средняя).
   `Single` — одиночный клик, `Double` — двойной.
3. `Repeat until stopped` работает до остановки; `Repeat … times` задаёт число повторений.
   **Одно повторение — один одиночный клик или одна пара кликов.** Например,
   3 повторения в режиме `Double` дают 6 кликов. Счётчики показывают оба числа.
4. `Start delay` — задержка перед запуском в секундах; ноль означает немедленный запуск.
5. `Current location` кликает в текущем положении мыши перед каждым повторением.
   Радиокнопка перед `Pick location` включает фиксированные X/Y (пиксели).
   Отрицательные координаты допустимы для мониторов слева/сверху основного.
   **Pick location** запускает трёхсекундный отсчёт: переместите курсор в нужную
   точку, и её координаты подставятся автоматически. Приложение только читает
   позицию мыши. Cancel / Esc отменяет выбор и сохраняет прежние X/Y.
6. Нажмите **Start**. **F6 переключает Start / Stop**, как указано на обеих кнопках.
   **F7** — отдельная клавиша остановки. Stop отменяет и задержку запуска.
   **Esc** останавливает только при фокусе в окне приложения.
7. **Hotkey setting** меняет переключатель Start / Stop и отдельную клавишу
   Emergency stop. Доступны F1–F12; клавиши должны различаться. Изменения
   сразу применяются и сохраняются. Cancel оставляет прежние назначения.
   **Help? >>** открывает встроенную справку.

Назначенные клавиши работают вне окна, в том числе с вводом средств доступности. Автоповтор
удерживаемой клавиши не создаёт новых запусков. Горячие клавиши не подавляются:
другая программа тоже может получить выбранные клавиши. При ошибке обработчика приложение
останавливается и показывает сообщение; ручные кнопки остаются доступны.

Во время ожидания и работы настройки заблокированы. Повторный Start игнорируется.
При быстром Stop → Start новый запуск принимается только после завершения
предыдущего потока; дождитесь доступности Start. Если команды клавиш пришли
в одном цикле интерфейса, Stop имеет приоритет. Ожидание интервала прерывается
сразу, но уже начатый вызов ОС (включая пару double) должен завершиться.

Интервал — пауза **после** завершённого повторения; это не таймер реального
времени. Фактическая частота зависит от ОС и времени обработки клика. Двойная
пара передаётся `pynput` одним вызовом; распознавание double-click целевой
программой также зависит от её поведения. Счётчик учитывает успешно завершённые
вызовы. Если ОС выбросила исключение посередине пары, часть ввода могла уже
дойти до цели, но незавершённое повторение не засчитывается.

## Настройки и ошибки

Настройки атомарно сохраняются при Start и нормальном закрытии:

- Windows: `%APPDATA%\autoclicker-in-python\settings.json`;
- Linux/macOS: `$XDG_CONFIG_HOME/autoclicker-in-python/settings.json`
  (по умолчанию `~/.config/autoclicker-in-python/settings.json`).

После перезапуска приложение **всегда остановлено**. Состояние запуска и счётчики
не сохраняются. Повреждённый файл заменяется стандартными настройками в памяти
с предупреждением; при следующем сохранении записывается валидный файл.
Неправильный ввод не заменяет последние сохранённые настройки.
Файлы предыдущей версии настроек (version 1) читаются автоматически: интервал
в секундах или миллисекундах раскладывается в четыре поля; остальные параметры
сохраняются. Новая запись использует version 2 с назначениями клавиш.

Пустые значения, неправильные форматы, NaN, бесконечность и недопустимые
диапазоны дают сообщения рядом с полями. Проверяются и неактивные поля
(их сохранённые значения должны оставаться корректными). Количество:
1–2147483647; координаты — знаковые 32-битные целые. Задержка допускает ноль,
интервал — нет. Очень большие интервалы/задержки ограничены `threading.TIMEOUT_MAX`.
Ошибка записи настроек показывается, но не мешает ручному запуску.

## Тестирование

Из корня репозитория:

```console
python -m unittest -v
python -m compileall -q .
```

Тестам достаточно стандартной библиотеки Python и Tk. Они **не кликают по
рабочему столу и не устанавливают глобальных обработчиков**: мышь и клавиатурный
listener подменены. Тесты GUI требуют доступного дисплея Tk и явно пропускаются
при его отсутствии. Ожидания движка управляются событиями и барьерами; случайных
`sleep()` нет. Ограничения времени служат только защитой от зависших тестов.

Покрыты валидация и восстановление после ошибки, все кнопки/режимы/позиции,
точное число повторений, отмена задержки, остановка длинного интервала,
конкурентные Start, Stop → Start с незавершённым вызовом мыши, исключения мыши
и создания потока, закрытие, обработка горячих клавиш, сохранение и повреждение
файла, отказ атомарной записи, отсутствие побочных эффектов импорта и связка Tk.

Код разделён на `ac_settings.py`, `ac_engine.py`, `ac_hotkeys.py`, `ac_gui.py`.
`autoclick.py` — точка входа. Импорт модулей не открывает окна, не создаёт мышь
и не устанавливает глобальные обработчики. Обновления Tk выполняются только
главным потоком; фоновый поток публикует состояние под блокировкой.

## Ручная проверка перед использованием

Начните с пустой безопасной области, `Repeat 3 times`, `Double`, интервал 500 мс,
задержка 5 с. Проверьте 3 повторения / 6 кликов. Затем проверьте отмену задержки,
F6/F7 из другого окна, ошибочный интервал и последующий правильный запуск.
Закройте и снова откройте приложение: настройки должны восстановиться,
а клики — не запускаться. Проверьте координаты на своей конфигурации мониторов.

Фактически выполненные проверки и ограничения перечислены в [TESTING.md](TESTING.md).
